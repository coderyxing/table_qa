# 新增查新记录与贡献边界

核验日期2026-11-06。本记录核验论文身份、摘要及部分方法描述，不表示已逐项复现或对齐数值，不声称完成穷尽查新。

|研究|已核验的相关思想|对本项目的约束|
|---|---|---|
|[ReasTAP，EMNLP2022](https://aclanthology.org/2022.emnlp-main.615/)|按推理技能模板生成合成问题，并用其训练表格推理能力|本轮96条合成技能材料是工程支撑和数据配方实验，不能将“合成技能课程”本身作为首次提出|
|[NormTab，Findings EMNLP2024](https://aclanthology.org/2024.findings-emnlp.203/)|通过表格规范化支持符号推理，讨论不规则单元格和结构|单位、名次和复合字段解析属于已有研究方向；不能把增加解析工具独立当主要创新|
|[TabVer，TACL2024](https://aclanthology.org/2024.tacl-1.89/)|关联声明片段、生成问题、在表上执行算术并结合自然逻辑形成可解释验证|“问题/声明片段对齐＋算术执行＋证据解释”的笼统组合已有；义务原型还需具体比较跨步骤状态保护、适用任务及验证形式|
|[Rethinking Table Instruction Tuning，arXiv v4/Findings ACL2025](https://arxiv.org/abs/2501.14693v4)|分析学习率/训练规模对表内、域外及一般能力的影响|不能预设更多训练样本或训练轮数一定更好；若本轮退化，需有控制地检查学习率和混合比例。其结果不直接决定本项目LoRA的最佳数值|
|[TableMaster，arXiv v6](https://arxiv.org/abs/2501.19378v6)|表格定位、语义表达及文本/符号自适应推理的综合框架|简单路由、表格转述或符号/文本组合不能直接当新贡献；后续强基线查新需覆盖此方向，当前未对齐其数值与测试协议|

来源均为论文作者/出版平台。TabVer主场景与本项目三任务并不完全相同；ReasTAP的任务覆盖也不等于FeTaQA。表中方法不得未经数据划分、指标、模型和训练条件核验就放在同一直接可比数值表。

当前两项**候选贡献**仍需落实到更具体的新增内容：第一项是已声明问题条件在操作链跨步骤/跨块执行中的义务保护、可恢复状态和来源审计；第二项是这类条件/来源/反馈约束下的改写与分块蒸馏。它们尚未被证明具有充分原创性或稳定增益；需与自然逻辑验证、程序约束及已有编译/依赖方法做进一步专项比较。

contracts.py目前只是严格操作绑定的独立验证器，不解决自然语言条件抽取完整性，也可能误拒不同但等价的程序。它未参与本轮学生课程试验，不得借用该试验结果证明验证器有效。论文应分别交代已有工具、独立实现、机制新增、受控实验和负向结果。
